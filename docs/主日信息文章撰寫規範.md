# 主日信息文章 —— 撰寫規範

## 固定收尾格式：今日行動提案表格

每篇主日信息文章的**最後**，固定加入一個行動提案表格，格式如下：

```markdown
## 今日行動提案：{一句話總結主題}

| 大點 | 聖經故事 | 本週具體挑戰 |
|------|---------|-----------|
| 1. {重點一簡稱} | {對應的聖經人物/故事} | {具體可執行的本週挑戰，一句話} |
| 2. {重點二簡稱} | {對應的聖經人物/故事} | {具體可執行的本週挑戰，一句話} |
| 3. {重點三簡稱} | {對應的聖經人物/故事} | {具體可執行的本週挑戰，一句話} |

{一段簡短總結，重複三個重點的關鍵詞}

這禮拜，你不需要做什麼驚天動地的大事。{一句鼓勵的收尾}

**{一句金句式的總結，適合被截圖分享}**
```

### 為什麼要這樣做

- 表格讓讀者一眼抓到「這篇信息 = 3個重點 + 3個可執行動作」，比純文字總結更容易被記住、被截圖分享
- 「本週具體挑戰」欄位要**具體可執行**（有動作、有時間感），不要寫抽象的期許（例如避免「更愛神」這種無法具體執行的句子）
- 最後的金句式總結，通常會被單獨截圖分享到社群，寫作時可以留意這句的獨立完整性（不依賴前文也能懂）

### 範例參考

見 `src/content/messages/2026-02-01-holiness.md` 與 `2026-09-06-follow-jesus.md` 的文末結構。

## 整體文章結構（固定骨架）

1. 開場經文引用（`>` blockquote，含出處）
2. 一段小故事或生活化的破題（吸引注意力，帶出主題）
3. 分點論述（通常 3 點，用 `##` 標題分段）
   - 每點包含：聖經原則說明 → 聖經故事印證（`**粗體小標**`）→ 現實生活應用案例
4. **今日行動提案表格**（固定收尾，見上方格式）
5. 總結收尾段落 + 一句金句式總結
