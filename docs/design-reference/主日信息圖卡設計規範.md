# 主日信息圖卡 —— 設計規範

參考素材：`sermon-cards/ref-01` ~ `ref-05`（凱西過去手動設計的五張範例）

---

## 固定不變（每週都要一致，才能累積品牌記憶）

| 元素 | 規範 |
|------|------|
| 版面比例 | 正方形 1:1（1080×1080） |
| 主標題顏色 | `#3D7318`（品牌深綠）或近黑色，不逐週更換 |
| 頂部標籤 | pill 形狀小標籤，淺綠底（`#EEF7E6`）+ 深綠字，文字如「本週主日信息」 |
| 重點條列格式 | 固定用數字「1、2、3、」，不與圓點混用 |
| 講員署名 | 固定置中偏下、固定字級 |
| HOPE 標誌位置 | 固定右下角，白色或深綠色，固定大小 |
| 字體 | 圓體/黑體中文（粗體），呼應網站 Noto Sans TC 的親和感 |

## 每週可調整

- 背景插畫主題可依當週信息內容調整氛圍（十字架、山丘、植物、光線等）
- **但色系必須收斂在**：綠色系（`#5BA826` / `#3D7318` / `#EEF7E6`）+ 米白/暖棕中性色
- 避免使用跳出此色系的顏色（例如粉紫色、桃紅色、鮮豔對比色）

## 實際產出方式（2026-09-14 更新——改用網頁截圖法，取代 AI 生圖）

上面的「AI 生圖提示詞模板」是原始構想，但實測後改採**網頁截圖法**：寫一份 HTML/CSS（六宮格版面：標題／裝飾／重點條列／插畫／HOPE標誌／講員署名），用本機瀏覽器 headless 模式截圖成 1080×1080 PNG。優點：版面精準可控、不依賴外部生圖服務、也不用等 AI 生圖的隨機性。

**六宮格版面對應：**

| 位置 | 內容 | 固定/可變 |
|------|------|-----------|
| 左上 | 主標題 | 固定：米白底（`#EEF7E6`）+ 深綠字（`#3D7318`）、64px、粗體 |
| 右上 | 裝飾圖形 | 可變：本週配色，圓形/雲朵造型 |
| 中左 | 三點重點條列 | 固定：淺綠底（`#5BA826`）+ 深綠字、37px、統一色調、「1、2、3、」同色前綴、行距一致（line-height 1.9） |
| 中右 | 插畫主題 | 可變：本週配色與意象，但收斂在綠色系＋米白/暖棕 |
| 左下 | HOPE 標誌 | 固定：米白底 + 深綠字、44px |
| 右下 | 講員署名 | 固定：置中、38px、白字 |

**精確版面數值（2026-09-14 用像素級量測 9/6 那張圖校正，之後直接套用，不用再目測）：**

- 整體：1080×1080
- 欄寬：左欄 626px／右欄 454px
- 列高：上排 282px／中排 578px／下排 220px（三個數字加總剛好 1080）
- 左上標題／中左條列／左下HOPE 三格的左右內距（padding）統一 **66px**
- 標題字級 64px（粗體900），條列文字字級 37px（粗體800），條列行距（line-height）約 1.84（對應原圖每行間距 68px）

**血淚教訓（2026-09-13 這篇的實際案例）：** 第一次改版時把「可變」的範圍想得太寬，連左上標題底色、中左重點條列底色都跟著整週配色換掉（例如換成深綠底白字），使用者當場指出「標題、文字字型、大小、位置和文字段落間距都要一致」——**固定的六格裡，只有右上裝飾、中右插畫、右下講員署名這三格背景色可以逐週變化，左上標題、中左條列、左下 HOPE 三格必須維持米白/淺綠底 + 深綠字的固定組合，不能因為想要「本週有變化」就連這幾格一起動。**

另外，重點條列的文字長度也要克制——每點盡量壓在一行內講完（例如「1、祂先愛了我們」），不要兩行落落長，跟原始五張範例的簡潔感才一致。

## 為什麼要這樣調整

原本五張範例圖插畫風格、色系、Logo 位置每週都不同（水彩花卉、3D玻璃感、木刻風格混雜），
單張好看，但累積不出品牌記憶。網站已建立清楚視覺語言（Hope Green、圓角卡片、pill 標籤），
圖卡統一色系與版面規則後，社群端與網站端會直接呼應，長期下來會形成一致的「一看就知道是希望教會」的辨識度。
