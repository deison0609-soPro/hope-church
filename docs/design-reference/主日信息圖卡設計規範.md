# 主日信息圖卡 —— 設計規範

參考素材：`sermon-cards/ref-01` ~ `ref-05`（凱西過去手動設計的五張範例）

---

## 固定不變（每週都要一致，才能累積品牌記憶）

| 元素 | 規範 |
|------|------|
| 版面比例 | 正方形 1:1（1080×1080） |
| 主標題顏色 | `#3D7318`（品牌深綠）或近黑色，不逐週更換 |
| 頂部標籤 | pill 形狀小標籤，淺綠底（`#EEF7E6`）+ 深綠字，文字如「本週主日信息」 |
| 重點條列格式 | 固定用數字「1、2、3、」，不與圓點混用 |
| 講員署名 | 固定置中偏下、固定字級 |
| HOPE 標誌位置 | 固定右下角，白色或深綠色，固定大小 |
| 字體 | 圓體/黑體中文（粗體），呼應網站 Noto Sans TC 的親和感 |

## 每週可調整

- 背景插畫主題可依當週信息內容調整氛圍（十字架、山丘、植物、光線等）
- **但色系必須收斂在**：綠色系（`#5BA826` / `#3D7318` / `#EEF7E6`）+ 米白/暖棕中性色
- 避免使用跳出此色系的顏色（例如粉紫色、桃紅色、鮮豔對比色）

## 為什麼要這樣調整

原本五張範例圖插畫風格、色系、Logo 位置每週都不同（水彩花卉、3D玻璃感、木刻風格混雜），
單張好看，但累積不出品牌記憶。網站已建立清楚視覺語言（Hope Green、圓角卡片、pill 標籤），
圖卡統一色系與版面規則後，社群端與網站端會直接呼應，長期下來會形成一致的「一看就知道是希望教會」的辨識度。
